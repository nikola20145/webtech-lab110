Purpose of this album

The importance of Authors are often downplayed in our society. From the beginning of time, storytellers used their knowledge and life experiences to send information, understanding, and wisdom to their community. As a result, knowledge has been passed down from generation to generation. This website is our contribution to shine light on our notoriuous Authors that have shaped our current world over our lifetime. Not many people know what it actually takes to be a great author. To be a great author you need:

  1. Attention to Detail
  2. Discipline
  3. Clarity
  4. Strong Vocabulary
  5. Open to Changes
  6. Passion for Reading

Browser Compatibility

Google Chrome: Since Google Chrome, was the main browser being used, the website was formatted to look its best when opened on it. Testing the HTML and CSS markup was relatively "easy" to implement, and mess around with.
Testing the different screen sizes definelty came with difficulty in the beginning. It was fascinating to see how much work web developers need to put in, in order to make sure that their website is compatible with so many devices.

Opera: When using Opera to test our website browser capability, in my opinion, the site
looked a bit cleaner and more high definitions. The colors were easier to see and I could clearly tell the difference between them and other colors. Besides that, the site looked just like as if it was opened on Google chrome.
We were unable to test out the different screen sizes on this web browser.

Microsoft Edge: When using Microsoft Edge, this web browser had a very obvious incompatibility with our html file. This was that the borders for the tables used in the HTML file would overlap the borders used to divide the website into different sections. Only on this web browser did this occur.
Everything else in the browser was pretty good. The different screen sizes feature was on par with Google Chrome, or maybe even better. Also, just like FireFox, I feel that the this web browser made the website graphically clearer. The issue with the table borders is also resolved when used on small screens on this web browser.

Firefox: When using FireFox, the only issue with compatibility was that some of the text would overlap with each other. This did not happen on any other of the web browsers. However, at first glance the site looks very clean.
The different screen size feature, personally, is better than Google Chrome, simply because it centers the website on the phone screen automatically. Finally, just like the other web browsers (excpet Chrome) the style was definelty more highly defined.
